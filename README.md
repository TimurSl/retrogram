# Retrogram

Telegram for Android with the classic (pre-Liquid-Glass) UI and current Telegram features, built from Telegram and Nagram XF, with the feature set of Graph Messenger (Databite).

See [PLAN.md](PLAN.md). Reference sources are pinned submodules in `upstream/` (`git submodule update --init`).

Detailed per-phase work packages: [docs/plans/](docs/plans/README.md).
